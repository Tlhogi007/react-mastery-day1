# React Mastery

Interactive learning platform to master React internals through hands-on exercises, visual diagrams, and real-world challenges.

**Live:** https://react-mastery-day1.vercel.app

## Features

- Interactive code playground
- Visual diagrams of React internals
- Quizzes and challenges
- Progress tracking
- Study mode
- Community articles (open contributions)

## Week 1 curriculum

- Day 1: Rendering Pipeline  
- Day 2: Reconciliation  
- Day 3: Fiber Architecture  
- Day 4: Bailouts & Memoization  
- Day 5: Effects & Closures  
- Day 6: Context & Re-renders  
- Day 7: Weekly Reflection  

## Tech stack

React 19 · TypeScript · Vite · Framer Motion

## Getting started

```bash
npm install
cp .env.example .env   # optional
npm run prepare:content
npm run dev
```

```bash
npm run build          # syncs content, then builds
```
