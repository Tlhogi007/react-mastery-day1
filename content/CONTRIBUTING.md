# Contributing to React Mastery Content

Thank you for wanting to share your React knowledge!

## What you can contribute

- Deep dives on React concepts
- Real-world bugs and fixes
- Interview questions and answers
- Code challenges with solutions
- Tips, diagrams, and gotchas

## How to contribute

### 1. Fork this repository

This is the **content-only** repo. You do not need the app codebase.

### 2. Add your article

```
community/
  your-github-username/
    understanding-fiber.md
```

### 3. Use this template

```markdown
---
title: "Your Title Here"
author: "Your Name"
github: "your-github-username"
twitter: "@yourhandle"
linkedin: "your-profile"
topic: "Fiber"
difficulty: "intermediate"
date: "2026-02-28"
tags: ["fiber", "performance", "debugging"]
estimatedTime: "10 min read"
---

# Your Title

## Introduction

Brief intro...

## The Problem

What issue does this address?

## The Solution

Explanation with code examples...

## Key Takeaways

- Point 1
- Point 2

## Further Reading

- [Link](https://example.com)
```

### 4. Submit a pull request

```bash
git add .
git commit -m "Add: Understanding Fiber Architecture"
git push origin your-branch
```

Then open a PR on GitHub.

## Guidelines

**Do:** explain clearly, include working code, credit sources, use proper markdown.

**Don't:** plagiarize, submit promotional content, use copyrighted images without permission.

## Review process

1. You open a PR
2. Maintainers review (usually within a few days)
3. Changes may be requested
4. After merge, the app syncs content on the next build
5. Your article appears on the Community page
